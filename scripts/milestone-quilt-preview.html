Milestone quilt preview

Throwaway prototype — not wired into the app. Each chapter is a generative 4:5 quilt with exactly N blocks for N colors. Same color history, denser as the count grows.

Open this file in a browser anytime: scripts/milestone-quilt-preview.html. Layout algorithm is a stand-in for the real chapter builder — same idea (recursive splits → N leaves → your colors), not the production module yet.
